# Pokémon Emerald Hardcore Nuzlocke

This repository contains a Pokémon Emerald Hardcore Nuzlocke ROM hack built on the [pret/pokeemerald](https://github.com/pret/pokeemerald) decompilation. 
This hack implements the Hardcore Nuzlocke ruleset as toggleable game settings, along with quality-of-life features, while staying faithful to the original Pokémon Emerald experience.

- See [FEATURES.md](FEATURES.md) for a full feature list & documentation.
- See [INSTALL.md](INSTALL.md) for full WSL/devkitARM toolchain & ROM build setup.
- See [Latest Releases](https://github.com/allenuh/emeraldnuzlocke/releases/latest) for .bps patch download.
